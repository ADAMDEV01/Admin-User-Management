# Admin User Management

A frontend application repository built with React and TypeScript, using Vite for development and production builds.

## Technology

- React 18
- TypeScript
- Vite 6
- Lucide React icons

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Skills demonstrated

- React component-based frontend development.
- TypeScript for typed UI code.
- Icon integration with Lucide React.
- Vite development and production build workflows.
